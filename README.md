## 🤖 Overview

SpeakoFlow records your speech, analyses pace, filler words, and pronunciation, then provides real-time coaching feedback to help you speak with more confidence.

Whether you're a newcomer or a veteran, SpeakoFlow provides the tools you need to get the most out of your ai tools experience. Designed for Windows and macOS, it delivers a seamless, high-performance workflow.

## ✨ Key Features

| Feature | Description |
|---|---|
| **Filler Detection** | Highlights ums, uhs, and filler phrases in your transcript |
| **Pace Monitor** | Tracks words-per-minute and flags sections that are too fast |
| **Pronunciation AI** | Phoneme-level feedback on mispronounced words |
| **Session History** | Track improvement trends across weeks of practice sessions |
